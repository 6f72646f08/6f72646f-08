# IAM // 08 — ARG signal

Одностраничная ARG-загадка с мотивами криптографического сообщества, цикады и протокола IAM: игрок восстанавливает зеркально записанный Base64-пакет и получает переход к следующему узлу.

Сайт не требует сборки: откройте `index.html` или разместите каталог через GitHub Pages.
